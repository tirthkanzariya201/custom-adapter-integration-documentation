title: Compatibility Matrix
description: Minimum OS versions and SDK compatibility per published package.
---

Confirm that your app meets these version floors before you integrate. This page states requirements as minimums and supported ranges. It does not list adapter versions TapMind currently ships.

Your app needs the floors below for the product you are integrating.

## Custom Adapter (GMA SDK)

### Android baseline

These Android floors apply to every mediation under this product.

| Requirement | Minimum |
|-------------|---------|
| minSdkVersion | 24 |
| compileSdkVersion | 35 (36 recommended) |
| Kotlin | 2.1.0 |
| Java | 17 |
| Android Gradle Plugin (AGP) | 8.6 |

### iOS baseline

The minimum iOS deployment target depends on your framework, not on mediation.

| Framework | Minimum iOS Deployment Target |
|-----------|-------------------------------|
| Native | 13.0 |
| Unity | 12.0 |
| Flutter | 15.0 |
| React Native | 15.0 |
| Cocos | 18.0 |

Xcode 26.0 or later is required. Supported dependency managers are CocoaPods and Swift Package Manager (SPM). When you integrate via SPM, the supported Google Mobile Ads SDK version is 12.14.0 up to but not including 14.0.0. All of 13.x is supported.

### Google Mobile Ads SDK

Google Mobile Ads (GMA) SDK version 25.0.0 or higher is required as the underlying demand SDK for every mediation in this product.

### Additional mediation SDK requirements

AdMob and Google Ad Manager require no additional SDK beyond the GMA version above. GMA is the mediation itself in both cases.

Also required:

- AdMob: AdMob App ID must be present in your app's manifest.
- Google Ad Manager: Your Google Ad Manager app ID must be present in your app's manifest.

AppLovin MAX and LevelPlay use GMA as demand underneath a separate mediation SDK. Your app also needs that mediation SDK at the floor below. Versions above the stated floor are supported and are usually fine, though untested beyond the version we have verified against.

| Mediation | Additional Mediation SDK Required |
|-----------|-----------------------------------|
| AppLovin MAX | 13.6.1 or higher, on every GMA SDK framework this mediation ships on |
| LevelPlay | 9.3.0 or higher, on every GMA SDK framework this mediation ships on |

Also required:

- AppLovin MAX: Your applovin.sdk.key must be present in your app's manifest.

### Example

Kotlin 2.1.0 is required even when GMA is already at 25. Meeting only the GMA floor is not enough.

| Publisher Has | TapMind Requires | Result |
|---------------|------------------|--------|
| Kotlin 1.9.24 with GMA 25 | Kotlin 2.1.0 or higher | Not compatible |

## Custom Adapter (GMA Next-Gen SDK)

This product currently ships these packages only:

- Native Android: AdMob, Google Ad Manager, LevelPlay
- Flutter Android: AdMob
- Unity Android: AdMob, LevelPlay

iOS is not yet supported for the Next-Gen SDK.

### Android baseline

These Android floors apply to every Next-Gen package listed above.

| Requirement | Minimum |
|-------------|---------|
| minSdkVersion | 24 |
| compileSdkVersion | 36 |
| Kotlin | 2.1.0 |
| Java | 17 |
| Android Gradle Plugin (AGP) | 8.6 |

### GMA Next-Gen SDK

The GMA Next-Gen SDK version required is 1.3.0 or higher.

### Additional mediation SDK requirements

AdMob and Google Ad Manager require no additional SDK beyond the GMA Next-Gen version above.

| Mediation | Additional Mediation SDK Required |
|-----------|-----------------------------------|
| LevelPlay (Native Android, Unity Android) | 9.3.0 or higher |

Flutter Next-Gen AdMob requires `google_mobile_ads` 9.0.0 or later.

## Orchestration SDK

| Requirement | Value |
|-------------|-------|
| Runtime Android API | 24 (Android 7.0) or higher |
| Compile minSdk | May stay 23. Below API 24 the SDK does not initialize (`UNSUPPORTED_VERSION`). |
| Other | Google Play services. `mavenCentral()`. |

Contact your account manager if you need confirmation for a specific package version before upgrading.
