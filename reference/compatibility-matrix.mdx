## Custom Adapter (GMA SDK)

### Core Development Stack

| Field | Requirement |
|-------|-------------|
| Development Framework / Engine | Native, Flutter, Unity, React Native, and Cocos are all supported. |
| Framework Version | See per-framework table below. |
| Primary Language (Android) | Java or Kotlin, both supported. |
| Kotlin/Java Version (Android) | Kotlin 2.1.0 or higher. Java 17 or higher. |
| Primary Language (iOS) | Swift or Objective-C, both supported. |

| Framework | Framework Version |
|-----------|-------------------|
| Native | **Not applicable**, no separate framework version. |
| Flutter | Dart SDK 3.6.0 or higher, Flutter SDK 3.27.0 or higher. |
| Unity | **[DEVELOPER TO CONFIRM: no minimum Unity version documented yet]** |
| React Native | 0.76.x or higher. |
| Cocos | **[DEVELOPER TO CONFIRM: no minimum Cocos version documented yet]** |

### Android Build Specifics

| Field | Requirement |
|-------|-------------|
| Minimum SDK Version (minSdkVersion) | 24 or higher |
| Compile SDK Version (compileSdkVersion) | 35 or higher (36 recommended) |
| Target SDK Version (targetSdkVersion) | **No TapMind-specific requirement.** Follow Google Play's current targetSdk policy. |
| Gradle Version | Must be compatible with your Android Gradle Plugin (AGP) version. **No separate TapMind-specific floor.** |
| Android Gradle Plugin (AGP) Version | 8.6 or higher |
| ProGuard / R8 Minification Enabled? | Supported whether enabled or not. **No additional keep rules required** beyond what is bundled with our library. |

### iOS Build Specifics

| Field | Requirement |
|-------|-------------|
| Minimum Deployment Target | See per-framework table below. |
| Xcode Version Used | 26.0 or higher |
| Dependency Manager | See table below. |

| Framework | Minimum iOS Deployment Target |
|-----------|-------------------------------|
| Native | 13.0 |
| Unity | 12.0 |
| Flutter | 15.0 |
| React Native | 15.0 |
| Cocos | 18.0 |

| Dependency Manager | Requirement |
|--------------------|-------------|
| CocoaPods | Supported, no additional constraints. |
| Swift Package Manager (SPM) | Supported. Google Mobile Ads SDK version must be 12.14.0 or higher and below 14.0.0 (all of 13.x is supported). |

### Current Monetization & Mediation Stack

| Field | Requirement |
|-------|-------------|
| Primary Mediation Platform | Determines which row below applies: AdMob, Google Ad Manager, AppLovin MAX, or LevelPlay. |
| Mediation SDK Version | See table below. |
| GMA SDK Version | Google Mobile Ads (GMA) SDK 25.0.0 or higher, required for every mediation listed above. |

| Mediation Platform | Mediation SDK Version Required |
|--------------------|--------------------------------|
| AdMob | **Not applicable**, same as the GMA SDK Version requirement above. |
| Google Ad Manager | **Not applicable**, same as the GMA SDK Version requirement above. |
| AppLovin MAX | 13.6.1 or higher |
| LevelPlay | 9.3.0 or higher |

### Additional manifest setup

| Mediation Platform | Also required in your app |
|--------------------|---------------------------|
| AdMob | AdMob App ID present in your app's manifest. |
| Google Ad Manager | Your Google Ad Manager app ID present in your app's manifest. |
| AppLovin MAX | Your applovin.sdk.key present in your app's manifest. |
| LevelPlay | **No manifest key required.** |

## Custom Adapter (GMA Next-Gen SDK)

Supported packages:

- Native Android: AdMob, Google Ad Manager, AppLovin MAX, LevelPlay
- Flutter Android: AdMob only
- Unity Android: AdMob and LevelPlay only

iOS is not yet supported for the Next-Gen SDK.

### Core Development Stack

| Field | Requirement |
|-------|-------------|
| Development Framework / Engine | Native Android, Flutter Android, and Unity Android are supported. |
| Framework Version | See per-framework table below. |
| Primary Language (Android) | Java or Kotlin, both supported. |
| Kotlin/Java Version (Android) | **[DEVELOPER TO CONFIRM: same as GMA SDK product or different?]** |

| Framework | Framework Version |
|-----------|-------------------|
| Native | **Not applicable**, no separate framework version. |
| Flutter | **[DEVELOPER TO CONFIRM: same as GMA SDK product or different?]** |
| Unity | **[DEVELOPER TO CONFIRM: same as GMA SDK product or different?]** |

### Android Build Specifics

| Field | Requirement |
|-------|-------------|
| Minimum SDK Version (minSdkVersion) | 24 or higher |
| Compile SDK Version (compileSdkVersion) | 36 or higher |
| Target SDK Version (targetSdkVersion) | **No TapMind-specific requirement.** Follow Google Play's current targetSdk policy. |
| Gradle Version | Must be compatible with your Android Gradle Plugin (AGP) version. **No separate TapMind-specific floor.** |
| Android Gradle Plugin (AGP) Version | 8.6 or higher |
| ProGuard / R8 Minification Enabled? | Supported whether enabled or not. **No additional keep rules required** beyond what is bundled with our library. |

### Current Monetization & Mediation Stack

| Field | Requirement |
|-------|-------------|
| Primary Mediation Platform | Determines which row below applies: AdMob, Google Ad Manager, AppLovin MAX (Native Android only), or LevelPlay (Native Android and Unity Android). |
| Mediation SDK Version | See table below. |
| GMA SDK Version | GMA Next-Gen SDK 1.3.0 or higher **[DEVELOPER TO CONFIRM this floor is current]** |

| Mediation Platform | Mediation SDK Version Required |
|--------------------|--------------------------------|
| AdMob | **Not applicable**, same as GMA Next-Gen SDK Version requirement above. |
| Google Ad Manager | **Not applicable**, same as GMA Next-Gen SDK Version requirement above. |
| AppLovin MAX (Native Android only) | **[DEVELOPER TO CONFIRM: same floor as GMA SDK product, 13.6.1, or a separate floor?]** |
| LevelPlay (Native Android and Unity Android) | **[DEVELOPER TO CONFIRM: same floor as GMA SDK product, 9.3.0, or a separate floor?]** |

Flutter Next-Gen AdMob requires `google_mobile_ads` 9.0.0 or later.

## Orchestration SDK

| Requirement | Value |
|-------------|-------|
| Runtime Android API | 24 (Android 7.0) or higher |
| Compile minSdk | May stay 23. Below API 24 the SDK does not initialize (`UNSUPPORTED_VERSION`). |
| Other | Google Play services. `mavenCentral()`. |

Contact your account manager if you need confirmation for a specific package version before upgrading.
