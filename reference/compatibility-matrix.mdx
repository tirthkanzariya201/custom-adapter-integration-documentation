Use this page to check a publisher's intake answers against what TapMind requires, field by field, before integration. Match the **What to check** column to the same field on the publisher intake form. Compare the publisher's answer to **What TapMind requires**. If the publisher is below the requirement, treat the app as **Not Compatible** until they upgrade.

Do not treat this page as a list of adapter versions TapMind currently ships. It states version floors and supported ranges only.

Common Android requirements (Custom Adapter, GMA SDK and GMA Next-Gen SDK):

- Minimum SDK Version (`minSdkVersion`) of **24** or higher
- Compile SDK Version (`compileSdkVersion`) of **35** or higher (**36** recommended)

#### AdMob and Google Ad Manager (GMA)

Use when **Primary Mediation Platform** is AdMob or Google Ad Manager (GAM). Also collect **GMA SDK Version**.

| What to check (intake field) | What TapMind requires | If the publisher is below this |
|------------------------------|----------------------|--------------------------------|
| GMA SDK Version | >= 25.0.0. Not supported: < 25.0.0 | Not Compatible. Ads fail to init or the app can crash. |
| Compile SDK Version (`compileSdkVersion`) | 35 or higher. Not supported: < 35 | Not Compatible. |
| Minimum SDK Version (`minSdkVersion`) | 24. Not supported: < 24 | Not Compatible. Init fails. |
| Kotlin/Java Version (Android), Kotlin | >= 2.1.0. Not supported: < 2.1.0 | Not Compatible. |
| Consent Management Platform (CMP) Used, Google UMP | User Messaging Platform (UMP) 4.x. Not supported: 2.x or 3.x | Not Compatible if they ship UMP 2.x or 3.x. |
| AdMob App ID in manifest | Present (`ca-app-pub-...`) | GMA can crash on launch without it. |
| Ad Formats to Integrate | Banner, interstitial, rewarded, native, and app open are in scope for AdMob. App open is AdMob only. | An unsupported format will not serve through TapMind. |
| ProGuard / R8 Minification Enabled? | If Yes, TapMind keep rules must be applied | Ads can fail at runtime after minification. |

#### Worked examples (LevelPlay)

TapMind's LevelPlay requirement is the 9.3.x line (examples use 9.3.0 as the floor TapMind is built against). Newer 9.3+ patches are compatible. Older 9.x before 9.3.x is not.

| Publisher has | TapMind requires | Outcome |
|---------------|------------------|---------|
| LevelPlay 8.8.0 | 9.3.x (built against 9.3.0) | Not Compatible |
| LevelPlay 9.0.0 | 9.3.x (built against 9.3.0) | Not Compatible |
| LevelPlay 9.3.0 | 9.3.x (built against 9.3.0) | Compatible |
| LevelPlay 9.5.0 | 9.3.x (built against 9.3.0) | Compatible (newer patch) |

#### Worked examples (AppLovin MAX)

Engineering has confirmed 12.x is not supported and 13.6.x is supported. Examples for versions between 12.x and 13.6.x, and for MAX newer than 13.6.x, are pending. Do not treat those as compatible or not compatible until engineering confirms.

| Publisher has | TapMind requires | Outcome |
|---------------|------------------|---------|
| MAX SDK 12.x | 13.6.x | Not Compatible |
| MAX SDK 13.6.x | 13.6.x | Compatible |
| MAX SDK newer than 13.6.x, or 13.x below 13.6.x | 13.6.x | Pending. Do not guess. |
