Use this page to confirm your app meets minimum OS requirements and dependency versions before integrating.

Common Android requirements:

- `minSdkVersion` of **24** or higher (Flutter and React Native). Native Android, Unity, and Next-Gen use the Min Android values in the tables below.
- `compileSdkVersion` of **36** or higher

## Package compatibility

### Custom Adapter (GMA SDK)

| Mediation Platform | Required GMA SDK | Required mediation SDK | Min Android | Min iOS |
|--------------------|------------------|------------------------|-------------|---------|
| AdMob | 25.0.0 | GAM SDK | 23 (native), 24 (Flutter/RN) | 12.0 (native), 15.0 (Flutter/RN) |
| Google Ad Manager | 25.0.0 | GAM SDK | 23 (native), 24 (Flutter/RN) | 12.0 (native), 15.0 (Flutter/RN) |
| AppLovin MAX | Compatible resolution (wrappers) | AppLovin MAX SDK | 23 (native), 24 (Flutter/RN) | 12.0 (native), 15.0 (Flutter/RN) |
| Unity LevelPlay | Compatible resolution (wrappers) | Unity LevelPlay SDK | 23 (native), 24 (Flutter/RN) | 12.0 (native), 15.0 (Flutter/RN) |

### Custom Adapter (GMA Next-Gen SDK)

| Mediation Platform | Required GMA Next-Gen SDK | Required mediation SDK | Min Android | Min iOS |
|--------------------|---------------------------|------------------------|-------------|---------|
| AdMob | 1.3.0 | GMA Next-Gen SDK | 23 (native), 24 (Flutter) | 12.0 or higher |
| Google Ad Manager | 1.3.0 | GMA Next-Gen SDK | 23 or higher | 12.0 or higher |
| Unity LevelPlay | 1.3.0 | Unity LevelPlay SDK | 23 or higher | 12.0 or higher |

Native Android Next-Gen requires **compileSdk 36**. Flutter Next-Gen AdMob requires `google_mobile_ads` 9.0.0 or later.

### Orchestration SDK

| Requirement | Value |
|-------------|-------|
| Runtime Android API | 24 (Android 7.0) or higher |
| Compile minSdk | May stay 23. Below API 24 the SDK does not initialize (`UNSUPPORTED_VERSION`). |
| Other | Google Play services. `mavenCentral()`. |

## Framework notes

| Framework | Min Android | Min iOS | Notes |
|-----------|-------------|---------|-------|
| Native Android | 23 | - | compileSdk 36 or higher |
| Native iOS | - | 12.0 | |
| Flutter | 24 | 15.0 | Requires `google_mobile_ads`. GMA Next-Gen Flutter AdMob requires `google_mobile_ads` 9.0.0 or later. Set `platform :ios, '15.0'` in `ios/Podfile` (minimum required by TapMind SDK). |

Contact your account manager if you need confirmation for a specific package version before upgrading.
