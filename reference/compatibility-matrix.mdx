## Custom Adapter (GMA SDK)

### Core Development Stack

| Field | Requirement |
|-------|-------------|
| Development Framework / Engine | Native, Flutter, Unity, React Native, and Cocos are all supported. |
| Framework Version | See per-framework table below. |
| Primary Language (Android) | Java or Kotlin, both supported. |
| Kotlin/Java Version (Android) | Kotlin **2.1.0** or higher. Java **1.8** or higher. |
| Primary Language (iOS) | Swift or Objective-C, both supported. |

| Framework | Framework Version |
|-----------|-------------------|
| Flutter | Dart SDK **3.6.0** or higher, Flutter SDK **3.27.0** or higher. |
| Unity | Unity **2019.4** and above. |
| React Native | **0.76.x** or higher. |
| Cocos | Cocos Creator **3.8.0** or later. |

### Android Build Specifics

| Field | Requirement |
|-------|-------------|
| Minimum SDK Version (minSdkVersion) | **24** or higher |
| Compile SDK Version (compileSdkVersion) | **35** or higher (**36** recommended) |
| Gradle Version | **8.7** or higher |
| Android Gradle Plugin (AGP) Version | **8.6** or higher |

### iOS Build Specifics

| Field | Requirement |
|-------|-------------|
| Minimum Deployment Target | See per-framework table below. |
| Xcode Version Used | **26.0** or higher |
| Dependency Manager | See table below. |

| Framework | Minimum iOS Deployment Target |
|-----------|-------------------------------|
| Native | **13.0** |
| Unity | **12.0** |
| Flutter | **15.0** |
| React Native | **15.0** |
| Cocos | **18.0** |

| Dependency Manager | Requirement |
|--------------------|-------------|
| CocoaPods | Supported, no additional constraints. |
| Swift Package Manager (SPM) | Supported. Google Mobile Ads SDK version must be **12.14.0** or higher and below **14.0.0** (all of **13.x** is supported). |

### Current Monetization & Mediation Stack

| Field | Requirement |
|-------|-------------|
| Primary Mediation Platform | Determines which row below applies: AdMob, Google Ad Manager, AppLovin MAX, or LevelPlay. |
| Mediation SDK Version | See table below. |
| GMA SDK Version | See GMA SDK Version table below. |

| Mediation Platform | Mediation SDK Version Required |
|--------------------|--------------------------------|
| AdMob | **25.0.0** or higher |
| Google Ad Manager | **25.0.0** or higher |
| AppLovin MAX | **13.6.1** or higher |
| LevelPlay | **9.3.0** or higher |

| Framework | GMA SDK Version (Android) | GMA SDK Version (iOS) |
|-----------|---------------------------|------------------------|
| Native | **25.0.0** or higher | **12.14.0** or higher and below **14.0.0** (all of **13.x** is supported). |
| Flutter | **8.0.0** or higher | **7.0.0** or higher |
| Unity | **11.0.0** or higher | **10.3.0** or higher |
| React Native | **16.1.0** or higher | **16.0.3** or higher |
| Cocos | **25.0.0** or higher (native GMA, not plugin version) | **12.14.0** or higher and below **14.0.0** (native GMA) |

### Additional manifest setup

| Mediation Platform | Also required in your app |
|--------------------|---------------------------|
| AdMob | Confirm the AdMob App ID in the app is the live App ID from the AdMob Console. Whose package name you shared with us. Do not use Google's test/sample App ID (`ca-app-pub-3940256099942544~…`). That will fail integration and no request will reach TapMind. |
| Google Ad Manager | Your Google Ad Manager app ID present in your app's manifest. |
| AppLovin MAX | Your applovin.sdk.key present in your app's manifest. |
| LevelPlay | **No manifest key required.** |

## Custom Adapter (GMA Next-Gen SDK)

### Core Development Stack

| Field | Requirement |
|-------|-------------|

| Framework Version | See per-framework table below. |

| Framework | Framework Version |
|-----------|-------------------|

### Android Build Specifics

| Field | Requirement |
|-------|-------------|

| Compile SDK Version (compileSdkVersion) | **36** or higher |
| Gradle Version | **8.7** or higher |
| Android Gradle Plugin (AGP) Version | **8.6** or higher |

### Current Monetization & Mediation Stack

| Field | Requirement |
|-------|-------------|

| Mediation Platform | Mediation SDK Version Required |
|--------------------|--------------------------------|
| AdMob | **25.0.0** or higher |

## Orchestration SDK

| Requirement | Value |
|-------------|-------|
| minSDK | 24 (Android 7.0) or higher. May stay 23. Below API 24 the SDK does not initialize (`UNSUPPORTED_VERSION`). |
| compileSDK | 35 or higher |
| targetSDK | 35 or higher |
| Other | Google Play services. `mavenCentral()`. |

Contact your account manager if you need confirmation for a specific package version before upgrading.
