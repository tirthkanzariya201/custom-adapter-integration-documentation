<Update label="June 3, 2026">

<p className="cl-version" id="version-2111">2.1.11</p>

Linked to core SDK version: [v1.2.6](/changelog/sdk/gma-mediation-ios#version-126)

<p className="cl-kind cl-added">Added</p>

- Introduced SDK Crash Prevention Guard Layer to improve stability and prevent common initialization failures. Guards added: OS Version Check, Double Initialization Protection, Parameter Validation, Mediation SDK Compatibility Check, Demand Partner Class Availability Check, Initialization Thread Validation, iOS Background Suspension Check.
- Added backend error logging for SDK guard failures to improve diagnostics and monitoring.
- Added Test Mode support to enable testing with dedicated test ad unit IDs.
- Added privacy consent collection and propagation support for downstream ad network integrations.

<p className="cl-kind cl-changed">Changed</p>

- Updated ad request handling to use Core Engine-provided ad sizes for Google Ad Manager (GAM) requests and demand partner ad fetching.
- Reduced ad request response payload size to optimize bandwidth usage and lower backend serving costs.
- Updated the server URL to srv.tmcadptr.com (latest backend serving domain infrastructure).

<p className="cl-kind cl-fixed">Fixed</p>

- Fixed the crash caused by multiple-time initialisation of the Google SDK: GMA initialization is now skipped when running under GAM or AdMob mediation.
- Prevented SDK crashes caused by invalid initialization states, unsupported environments, missing dependencies and configuration issues; improved error handling and reporting across initialization and mediation setup.

</Update>
