<Update label="August 24, 2026">

<p className="cl-version" id="version-2113">2.1.13</p>

Linked to core SDK version: [v3.0.5](/changelog/sdk/gma-mediation-ios#version-305)

<p className="cl-kind cl-added">Added</p>

- Added and passed the required parameters (Test Mode, Ad Height, Ad Width) in the Bid Request API.
- Added product key parameter in the Bid Request and Impression APIs.
- Handled multiple ad scenarios and ensured proper thread management.
- Implemented ad timeout logic to avoid blocking the overall ad flow.
- Implemented ad refresh logic.

- Enabled and added the necessary logs at key points in the ad request and response flow.
